FishingLog 1.3 FR5 - adaptation française Dusk

FR5 :
- conserve les 51 noms français vérifiés issus des listes de pêche/prowesses LOTRO ;
- relance automatiquement le résolveur AUTOFR (version 2) sur les IDs de la base ;
- mémorise les noms localisés renvoyés par le client français dans FL_Names ;
- affiche à la fin du scan le nombre de prises possédant un nom français ;
- /fl fr permet de relancer le scan manuellement ;
- aucune traduction non vérifiée n’est injectée pour les IDs restants.

Les corrections FR4 de l’interface, des options, des quêtes et des lieux sont conservées.
